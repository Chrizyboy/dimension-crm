# Versionen

Was in jeder Version neu ist. Der Abschnitt der aktuellen Version (`version` in `package.json`) erscheint in der
Desktop-App im Fenster «Neue Version». Kurz und für das Team geschrieben, nicht für Entwickler.
Neue Version: Abschnitt oben ergänzen, `version` in `package.json` erhöhen, dann auf GitHub «Neue Version
veröffentlichen» starten (docs/installation.md).

## 0.16.0

- Desktop-App für Windows mit automatischen Updates: Neue Versionen erscheinen oben als «Update», installiert wird erst nach deinem Klick.
- Datensicherung wie bisher um 12:00 und 16:00, mit Kopie in SharePoint, herunterladen und wiederherstellen (Administration).
- «Erste Schritte» im Handbuch: Installieren, Anmelden und die wichtigsten Abläufe auf zwei Seiten.
