Dimension Work installieren

Unser CRM für Verkauf, Projekte, Service und Baustelle. Am PC als App, auf dem Handy direkt im Browser.

Am PC (Windows)

Die App startet schnell, meldet sich bei neuen Mails und aktualisiert sich selbst.

Für Windows herunterladen

Auf dem Handy

Öffnen und «Zum Home-Bildschirm» wählen. Dann ist Dimension Work wie eine App auf dem Handy.

Im Browser öffnen
Adresse: work.dimension-solaire.ch

So geht’s am PC

  1. Herunterladen
    Oben auf den orangen Knopf klicken.
  2. Datei öffnen
    Die heruntergeladene Datei öffnen. Es braucht keine Administratorrechte.
  3. Falls Windows warnt
    Erscheint «Der Computer wurde durch Windows geschützt»: auf «Weitere Informationen» und dann «Trotzdem ausführen» klicken. Das kommt nur beim ersten Mal.
  4. Anmelden
    Mit der eigenen Geschäfts-Mail anmelden. Der Code kommt per Mail. Updates installieren sich danach von selbst.
